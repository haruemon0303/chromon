# 時の絆：起源

ピュアHTML5、CSS、JavaScriptで作られたゲームボーイ風モンスター収集RPG

## 🎮 今すぐプレイ

このゲームはインストール不要でブラウザで直接遊べます！

**GitHub Pages URL:** `https://<username>.github.io/chromon/`

## 📖 ストーリー

カゲン諸島へようこそ。古代遺跡と現代技術が共存する不思議な土地です。中央には「時渡りの大樹」と呼ばれる、過去と未来を繋ぐ神秘的な存在が佇んでいます。

若き探索者として、あなたは2つの時間軸を旅し、仲間となる生物を集め、野生のモンスターと戦い、時間そのものの謎を解き明かします。ある時代での選択が、別の時代の地形やイベントに影響を与えるかもしれません。

## ✨ 機能

### MVP実装内容（v1.0）

- **フィールド探索** - タイルベースマップでの移動と衝突判定
- **NPC対話** - 村人やキャラクターとの会話
- **ランダムエンカウント** - 草むらエリアでの野生生物との遭遇
- **ターン制バトル** - 「たたかう」「どうぐ」「にげる」の戦略的1対1戦闘
- **捕獲システム** - 捕獲オーブでパーティに追加（最大3体）
- **時間軸切替（Phase1実装）** - 古代と現代を行き来し、選択が未来に影響
  - 画面右上に現在の時代を表示
  - 古代での選択（倒木をどける/残す）が現代の地形に反映
  - 選択によって通行可能なエリアが変化
- **セーブ/ロード** - ブラウザのlocalStorageに進行を保存（時代・選択も保存）
- **完全オリジナル** - 全ての生物、技、名称が100%オリジナル
- **モバイル最優先** - iPhoneに最適化されたタッチ操作
- **ゲームボーイ風** - 本物の160x144解像度、緑モノクロパレット
- **生成音声** - Web Audio APIで全効果音を動的生成

## 🎯 操作方法

### タッチ操作（モバイル）
- **十字キー** - 上下左右に移動
- **Aボタン** - 決定、調べる、NPCと会話
- **Bボタン** - キャンセル、戻る
- **メニューボタン** - セーブ/ロード/設定画面を開く

### キーボード操作（PC）
- **矢印キー** - キャラクター移動
- **Z / Enter** - Aボタン（決定/調べる）
- **X / Escape** - Bボタン（キャンセル）
- **M** - メニューを開く

## 🗺️ 遊び方

1. **冒険の始まり**
   - イントロメッセージを読む
   - 北にある研究所（扉のある建物）まで歩く
   - 扉タイルに乗って中に入る

2. **最初の仲間を入手**
   - 研究所内の助手に話しかける（向いてAボタン）
   - 3体の中から1体を選択：
     - **メビー**（草タイプ） - バランス型
     - **ヒコ**（炎タイプ） - 高速・高攻撃
     - **スイヒレ**（水タイプ） - 高防御

3. **探索と戦闘**
   - 研究所を出て村を探索
   - 草むらを歩くとランダムエンカウント発生
   - 野生生物と戦って経験を積む

4. **新しい仲間を捕獲**
   - 戦闘中、「どうぐ」→「捕獲オーブ」を選択
   - 成功率は敵のHP（低いほど捕まえやすい）に依存
   - 最大3体までパーティに編成可能

5. **時間軸の移動を体験（Phase1機能）**
   - 南に進んで「時渡りの大樹」イベント地点を見つける
   - 調べる（Aボタン）で古代へタイムスリップ
   - 古代で案内人（y=10付近のNPC）に話しかける
   - **重要な選択**：倒木を「どける」or「そのままにする」
   - 現代に戻ると、選択に応じて地形が変化：
     - 「どける」→ 現代で新しい道が開通
     - 「そのままにする」→ 現代でも道が塞がったまま
   - 画面右上に「古代」「現代」の表示が切り替わる

6. **進行を保存**
   - メニューボタンを押す
   - 「セーブ」で進行をlocalStorageに保存
   - 「ロード」で以前のセーブを復元
   - リセットで最初からやり直し（警告：元に戻せません！）

## 🎨 技術詳細

### 技術スタック
- **依存なし** - ピュアHTML/CSS/JavaScript
- **Canvas描画** - ピクセルパーフェクトな2Dコンテキスト
- **Web Audio API** - 手続き的に生成される効果音
- **localStorage** - クライアント側セーブデータ永続化

### 互換性
- **主要ターゲット** - iPhone Safari（iOS 14以降）
- **対応環境** - モダンなデスクトップブラウザ（Chrome、Firefox、Safari、Edge）
- **表示** - 縦画面推奨
- **解像度** - 160x144（ゲームボーイ）を画面に合わせて拡大

### パフォーマンス
- 軽量：合計 約60KB（非圧縮）
- 初回ロード後、外部アセットやネットワーク要求なし
- モダンデバイスで60 FPS動作

## 🎵 オーディオ

全ての効果音はWeb Audio オシレーターでリアルタイム生成：
- **歩行音** - 移動時
- **選択音** - メニュー選択
- **エンカウント** - 戦闘開始
- **攻撃音** - 技使用
- **捕獲音** - オーブ投げアニメーション
- **成功音** - 捕獲成功/勝利ファンファーレ
- **失敗音** - 捕獲失敗/敗北

音量とON/OFFはゲーム内設定メニューで制御可能。

## 🔧 開発

### ローカルテスト
```bash
# ローカルで配信（任意の静的サーバでOK）
python -m http.server 8000
# または
npx serve
```

### カスタマイズ

**新しい生物を追加**: `data/creatures.json`を編集
```json
{
  "id": "newmon",
  "name": "ニューモン",
  "type": "属性",
  "baseStats": {...},
  "moves": ["move_id"],
  "captureRate": 45
}
```

**新しい技を追加**: `data/moves.json`を編集
```json
{
  "id": "move_id",
  "name": "技名",
  "power": 50,
  "accuracy": 90,
  "type": "属性"
}
```

**新しいマップを作成**: `data/world.json`を編集
- タイル配置を定義
- 衝突レイヤーを設定
- NPC、ワープ、イベントを追加
- エンカウントゾーンを設定

**会話を変更**: `data/dialogue.json`を編集
- 既存の会話を更新
- 新しい会話シーケンスを追加
- 分岐選択肢を作成

### カラーパレット

ゲームはデフォルトでゲームボーイグリーンを使用。色を変更するには、`style.css`のCSS変数を変更：

## 🕰️ Phase1: 時間軸システム（実装済み）

### コンセプト：Chrono Bonds - ORIGIN / DESTINY

ゲームの核心機能である「二重時間軸」と「選択による未来への影響」を実装しました。

#### 実装内容

1. **時代の行き来**
   - 現代（カゲン村・現代）と古代（カゲン村・古代）を移動可能
   - 画面右上に常に現在の時代を表示
   - セーブ/ロードで時代も保存・復元

2. **選択による地形変化**
   - 古代で「倒木をどける」選択をした場合
     → 現代で y=9-10, x=8-10 エリアの通行が可能に
   - 「そのままにする」選択をした場合
     → 現代でも障害物が残り、通行不可のまま

3. **技術実装**
   - `applyTimelineChanges()`: 選択に応じて現代マップのタイル・衝突判定を動的変更
   - `ancient_tree_removed` フラグで選択を記録
   - 時代切替時に自動的に地形を反映

4. **遊び方**
   - 南の「時渡りの大樹」で古代へ移動
   - 古代のy=10付近にいるNPCに話しかけて選択
   - 大樹に戻って現代へ戻る
   - 選択した結果が地形に反映されているか確認

### 次のフェーズ予定（Phase2以降）

- 複数の選択肢と分岐ストーリー
- 選択によるNPCの出現/消失
- より多くのタイムライン（3時代以上）
- 選択の組み合わせによる複雑な未来への影響
- パラレルワールド的な展開
