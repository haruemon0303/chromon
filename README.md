# 時の絆：起源

ピュアHTML5、CSS、JavaScriptで作られたゲームボーイ風モンスター収集RPG

## 🎮 今すぐプレイ

このゲームはインストール不要でブラウザで直接遊べます！

**GitHub Pages URL:** `https://<username>.github.io/chromon/`

## 📖 ストーリー

カゲン諸島へようこそ。古代遺跡と現代技術が共存する不思議な土地です。中央には「時渡りの大樹」と呼ばれる、過去と未来を繋ぐ神秘的な存在が佇んでいます。

若き探索者として、あなたは2つの時間軸を旅し、仲間となる生物を集め、野生のモンスターと戦い、時間そのものの謎を解き明かします。ある時代での選択が、別の時代の地形やイベントに影響を与えるかもしれません。

## ✨ 機能

### MVP実装内容（v1.0）

- **フィールド探索** - タイルベースマップでの移動と衝突判定
- **NPC対話** - 村人やキャラクターとの会話
- **ランダムエンカウント** - 草むらエリアでの野生生物との遭遇
- **ターン制バトル** - 「たたかう」「どうぐ」「にげる」の戦略的1対1戦闘
- **捕獲システム** - 捕獲オーブでパーティに追加（最大3体）
- **時間軸切替（Phase1実装）** - 古代と現代を行き来し、選択が未来に影響
  - 画面右上に現在の時代を表示
  - 古代での選択（倒木をどける/残す）が現代の地形に反映
  - 選択によって通行可能なエリアが変化
- **セーブ/ロード** - ブラウザのlocalStorageに進行を保存（時代・選択も保存）
- **完全オリジナル** - 全ての生物、技、名称が100%オリジナル
- **モバイル最優先** - iPhoneに最適化されたタッチ操作
- **ゲームボーイ風** - 本物の160x144解像度、緑モノクロパレット
- **生成音声** - Web Audio APIで全効果音を動的生成

## 🎯 操作方法

### タッチ操作（モバイル）
- **十字キー** - 上下左右に移動
- **Aボタン** - 決定、調べる、NPCと会話
- **Bボタン** - キャンセル、戻る
- **メニューボタン** - セーブ/ロード/設定画面を開く

### キーボード操作（PC）
- **矢印キー** - キャラクター移動
- **Z / Enter** - Aボタン（決定/調べる）
- **X / Escape** - Bボタン（キャンセル）
- **M** - メニューを開く

## 🗺️ 遊び方

1. **冒険の始まり**
   - イントロメッセージを読む
   - 北にある研究所（扉のある建物）まで歩く
   - 扉タイルに乗って中に入る

2. **最初の仲間を入手**
   - 研究所内の助手に話しかける（向いてAボタン）
   - 3体の中から1体を選択：
     - **メビー**（草タイプ） - バランス型
     - **ヒコ**（炎タイプ） - 高速・高攻撃
     - **スイヒレ**（水タイプ） - 高防御

3. **探索と戦闘**
   - 研究所を出て村を探索
   - 草むらを歩くとランダムエンカウント発生
   - 野生生物と戦って経験を積む

4. **新しい仲間を捕獲**
   - 戦闘中、「どうぐ」→「捕獲オーブ」を選択
   - 成功率は敵のHP（低いほど捕まえやすい）に依存
   - 最大3体までパーティに編成可能

5. **時間軸の移動を体験（Phase1機能）**
   - **大樹の場所**：村の南（座標x=9, y=12付近）にある「時渡りの大樹」
   - **初回**：大樹のイベント地点でAボタンを押すと古代へタイムスリップ（演出あり）
   - **2回目以降**：大樹の前でAボタンを押すだけで古代⇔現代を自由に切替可能
   - 画面上部のステータスバーに「時代：古代/現代」が表示されます

   **古代での重要な選択：**
   - 古代で案内人（y=10付近のNPC）に話しかける
   - **重要な選択**：倒木を「どける」or「そのままにする」
   - 現代に戻ると、選択に応じて地形が変化：
     - 「どける」→ 現代で新しい道が開通
     - 「そのままにする」→ 現代でも道が塞がったまま

6. **進行を保存**
   - メニューボタンを押す
   - 「セーブ」で進行をlocalStorageに保存
   - 「ロード」で以前のセーブを復元
   - リセットで最初からやり直し（警告：元に戻せません！）

## 🎨 技術詳細

### 技術スタック
- **依存なし** - ピュアHTML/CSS/JavaScript
- **Canvas描画** - ピクセルパーフェクトな2Dコンテキスト
- **Web Audio API** - 手続き的に生成される効果音
- **localStorage** - クライアント側セーブデータ永続化

### 互換性
- **主要ターゲット** - iPhone Safari（iOS 14以降）
- **対応環境** - モダンなデスクトップブラウザ（Chrome、Firefox、Safari、Edge）
- **表示** - 縦画面推奨
- **解像度** - 160x144（ゲームボーイ）を画面に合わせて拡大

### パフォーマンス
- 軽量：合計 約60KB（非圧縮）
- 初回ロード後、外部アセットやネットワーク要求なし
- モダンデバイスで60 FPS動作

## 🎵 オーディオ

全ての効果音はWeb Audio オシレーターでリアルタイム生成：
- **歩行音** - 移動時
- **選択音** - メニュー選択
- **エンカウント** - 戦闘開始
- **攻撃音** - 技使用
- **捕獲音** - オーブ投げアニメーション
- **成功音** - 捕獲成功/勝利ファンファーレ
- **失敗音** - 捕獲失敗/敗北

音量とON/OFFはゲーム内設定メニューで制御可能。

## 🔧 開発

### ローカルテスト
```bash
# ローカルで配信（任意の静的サーバでOK）
python -m http.server 8000
# または
npx serve
```

### カスタマイズ

**新しい生物を追加**: `data/creatures.json`を編集
```json
{
  "id": "newmon",
  "name": "ニューモン",
  "type": "属性",
  "baseStats": {...},
  "moves": ["move_id"],
  "captureRate": 45
}
```

**新しい技を追加**: `data/moves.json`を編集
```json
{
  "id": "move_id",
  "name": "技名",
  "power": 50,
  "accuracy": 90,
  "type": "属性"
}
```

**新しいマップを作成**: `data/world.json`を編集
- タイル配置を定義
- 衝突レイヤーを設定
- NPC、ワープ、イベントを追加
- エンカウントゾーンを設定

**会話を変更**: `data/dialogue.json`を編集
- 既存の会話を更新
- 新しい会話シーケンスを追加
- 分岐選択肢を作成

## ⚔️ 戦闘バランス調整（STEP2実装済み）

### 序盤で勝てる&学べるバランスに

理不尽に負けず、プレイヤーが戦略を学べるバランスに調整しました。

#### 現状分析と問題点

**調整前の問題：**
1. ガンカクが強すぎる（Atk 65, Def 70, Lv3-6）
   - Lv5の御三家vs Lv5のガンカク → 2-3ターンで倒される
   - 御三家は5ターン以上必要で一方的
2. 逃走率50%で運ゲー化
3. 回復アイテム50%回復で焼け石に水

#### バランス調整内容

1. **モンスターステータス調整**
   - フウヨク: Lv2-4 → Lv3-5、ステータス微増
   - ガンカク: 全ステータス10%減、Lv3-6 → Lv4-7
   - 捕獲率を全体的に微調整（45-50%）

2. **ダメージ計算式改善**
   ```javascript
   // 調整前: damage = (power * atk / def * 0.4 + 2) * random
   // 調整後: damage = (power * atk / def * levelMod * 0.35 + 2) * random
   ```
   - 倍率を0.4→0.35に下方修正
   - レベル補正追加（1 + level/50）
   - 序盤のダメージ約15%減で生存性向上

3. **逃走率向上**
   - 基本確率: 50% → 70%
   - 速度差でさらに補正
   - 序盤の理不尽な全滅を回避可能に

4. **回復アイテム強化**
   - 回復草: 50% → 60%回復
   - 戦略的に使えば逆転可能

5. **捕獲率改善**
   - HP100% → 基本捕獲率
   - HP50% → 1.5倍
   - HP25% → 2倍
   - HP1% → 3倍
   - HPを削るほど成功率が体感で上昇

#### 期待されるゲーム体験

- 同レベル戦: 平均5-7ターンで勝利
- 敵の攻撃: プレイヤーHPの15-20%/ターン
- 序盤3戦: 操作を理解すれば全滅しにくい
- 捕獲: HP半分以下で成功率実感
- 逃走: 70%以上で安定して逃げられる

#### 序盤の勝ち方（攻略ヒント）

1. **草むらの最初の敵（Lv3-5）を狙う**
   - フウヨク（風）が出やすい
   - 御三家と同レベルで練習に最適

2. **ガンカク（岩）は避けるorすぐ逃げる**
   - Lv4-7で強敵
   - 逃走率70%なので無理せず逃げてOK

3. **回復草を温存**
   - HPが30%以下になったら使用
   - 戦闘前に全回復推奨

4. **捕獲はHP黄色以下で**
   - HP50%以下で成功率大幅アップ
   - HP25%以下なら2倍の確率

5. **タイプ技を使い分け**
   - 草→水、水→岩、炎→草で有利（Phase2で実装予定）

## 🎨 グラフィック統一（STEP3実装済み）

### 統一感のあるゲームボーイ風ドット絵

同じ世界のルールで描かれた、判別しやすいグラフィックに統一しました。

#### 描画ルール

1. **統一仕様**
   - サイズ: 16x16ピクセル基本（戦闘時は拡大）
   - 4色パレット: #0f380f, #306230, #8bac0f, #9bbc0f
   - アウトラインと影の太さを統一
   - ミニマルなゲームボーイ風デザイン

2. **主人公**
   - 明るい緑（#8bac0f）の頭部
   - 濃い緑（#0f380f）の体
   - 方向で目の位置が変化
   - 16x16サイズで明確に判別可能

3. **NPC**
   - 博士: 帽子付きで識別
   - 村人: シンプルな体型
   - 主人公との色違いで区別
   - 目と体の構造を統一

4. **モンスター**
   - 各モンスター固有のシルエット
   - メビー: 芽の尻尾
   - ヒコ: 炎マーク
   - スイヒレ: ヒレ
   - フウヨク: 翼
   - ガンカク: 石の角
   - 戦闘時は2倍サイズで表示
   - プレイヤー側は左右反転表示

5. **戦闘画面**
   - 敵: 右上、2倍サイズ
   - 味方: 左下、1.5倍サイズ、反転
   - 位置とサイズを固定で分かりやすく

#### 実装方法

- Canvas 2Dコンテキストで図形描画
- スプライトシート不要（軽量）
- カラーは定数で管理（Colors）
- 描画関数を統一化：
  - drawPlayer()
  - drawNPC()
  - drawCreature()

#### 利点

- ファイル不要で軽量
- 4色パレットで統一感
- 16x16で拡大しても綺麗
- すべて同じルールで描画

## 🕰️ Phase1: 時間軸システム（実装済み）

### コンセプト：Chrono Bonds - ORIGIN / DESTINY

ゲームの核心機能である「二重時間軸」と「選択による未来への影響」を実装しました。

#### 実装内容

1. **時代の行き来**
   - 現代（カゲン村・現代）と古代（カゲン村・古代）を移動可能
   - 画面右上に常に現在の時代を表示
   - セーブ/ロードで時代も保存・復元

2. **選択による地形変化**
   - 古代で「倒木をどける」選択をした場合
     → 現代で y=9-10, x=8-10 エリアの通行が可能に
   - 「そのままにする」選択をした場合
     → 現代でも障害物が残り、通行不可のまま

3. **技術実装**
   - `applyTimelineChanges()`: 選択に応じて現代マップのタイル・衝突判定を動的変更
   - `ancient_tree_removed` フラグで選択を記録
   - 時代切替時に自動的に地形を反映

4. **遊び方**
   - 南の「時渡りの大樹」で古代へ移動
   - 古代のy=10付近にいるNPCに話しかけて選択
   - 大樹に戻って現代へ戻る
   - 選択した結果が地形に反映されているか確認

### 次のフェーズ予定（Phase2以降）

- 複数の選択肢と分岐ストーリー
- 選択によるNPCの出現/消失
- より多くのタイムライン（3時代以上）
- 選択の組み合わせによる複雑な未来への影響
- パラレルワールド的な展開
